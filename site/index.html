Firecracker sandboxes on the Kubernetes you already run.

Idle sandboxes save their memory and disk to S3, releasing VM memory. The next request restores their processes on a node with room.

Install guide Source on GitHub

Self-hosted, x86_64 with KVM only. No hosted service. loam-api runs as a single replica, so restarts interrupt the API and sandbox URLs. See isolation limits and E2B gaps.

# point the E2B SDK at your loam
pip install e2b
export E2B_DOMAIN=e2b.loam.example.com
export E2B_API_KEY=loam_...
from e2b import Sandbox

sbx = Sandbox.create()
print(sbx.commands.run("uname -a").stdout)
sbx.pause()     # snapshot to S3, VM off the node
sbx.connect()   # wake it, processes intact

Across the unmodified official Python and JS SDKs, 26 of 26 conformance steps pass for the supported surface. Template builds are unsupported. See E2B coverage.

E2B coverage

What the adapter serves

Supported

  • Create, get, kill, timeout, filtered list
  • Commands, files and streaming
  • Pause, resume and their automatic modes
  • Sandbox ports
  • Internet toggle and egress by name
  • One metrics sample and health

Not supported

  • Template builds
  • E2B snapshot and fork endpoints
  • Volumes
  • Sandbox logs and metrics history
  • CIDR and IP egress rules
  • secure:false, allowPublicTraffic:false

Checkpoints and forks are available through loam's native API. Full coverage and differences

The boundary

What a sandbox can reach

The nodelet enforces the boundary outside the guest. A sandbox with egress rules gets TCP over IPv4 only.

Scroll the diagram horizontally →

Brokered values stay out of guest memory, disk and snapshots. Secrets the application writes itself are outside that protection.

Sandboxes have OIDC identity. VMs share their unprivileged nodelet's cgroup and memory limit.

Run it

What you need

  • Kubernetes on x86_64 with KVMBare metal or nested virtualization
  • Linux 6.1 or newerFor /dev/userfaultfd
  • Device plugin/dev/kvm, /dev/net/tun, /dev/userfaultfd
  • XFS reflink directory on each nodeAn XFS image on ext4 works
  • Postgres
  • S3-compatible bucket
  • Wildcard DNS and TLSAPI, port and E2B domains

Follow the install guide with the kustomize base and example overlay.

git clone https://github.com/arugula-salad/loam
cp -r loam/deploy/examples/basic my-loam
# set your domain, store URL, ingress and secrets in my-loam
kubectl kustomize my-loam | less
kubectl apply -k my-loam

For single-machine development, the local recipe uses an in-memory database that disappears on exit.

Contribute

What would help

Send install reports from Talos, kubeadm, Hetzner or OVH bare metal, or cloud instances with nested virtualization. Contributions toward per-VM cgroups and E2B gaps would help.

Network after a move

A moved sandbox lost networking for 30 seconds. Random bridge MACs left stale guest ARP entries. Every node's bridge now uses a fixed MAC.

Chrome through the proxy

Headless Chrome's ECH GREASE triggered the egress filter's ECH rejection. The proxy now judges the outer SNI name.
